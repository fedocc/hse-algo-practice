# Установка с помощью GPT

Скопируй помощнику запрос ниже и добавь ссылку на этот GitHub-репозиторий. Инструкция предназначена для GPT/Codex с доступом к файлам и терминалу. Без такого доступа помощник должен давать команды тебе, не утверждая, что выполнил их сам.

## Готовый запрос

> Установи мне локально Algo Practice из этого репозитория. Прочитай README.md и AGENTS.md. Нужен новый независимый старт:0 решённых, пустые черновики, заметки и история, таймер 60:00. Не используй прогресс и браузерные данные автора.
>
> Определи мою ОС и доступный Python. Положи проект в постоянную папку пользователя, не в Downloads и не во временную папку. Если у меня уже есть этот тренажёр, сначала сохрани data/state.json и спроси, нужно обновить существующую установку или создать отдельную: не обнуляй её автоматически.
>
> Нужен Python 3.11+. Не устанавливай Node/npm или pip-зависимости для обычного запуска: редактор уже внутри. Если Python отсутствует, помоги поставить его из официального источника; не вводи за меня пароль администратора. На Windows используй py -3, при несовместимости — WSL. Учти, что фактически проверенная платформа этой версии — macOS.
>
> Проверь, что порт 8765 свободен. Не останавливай неизвестный процесс и не открывай сервер наружу. Запусти launch.py выбранным Python. Открой http://127.0.0.1:8765 и проверь каталог,0/200, пустую историю и таймер. Проверь локальный Run и Debug на временных тестовых данных, не оставляя мне фиктивных решений или зачтённых задач. Не отправляй тестовый код в LeetCode/Контест.
>
> Сначала достаточно локального режима. Если я попрошу официальную отправку, помоги загрузить папку extension в Dia или совместимый Chromium-браузер и привязать мой ID через bind_extension.py. Пароли ввожу я; не читай cookies, ключи или файлы профиля. Первую проверку вставки делай в режиме «Только вставить код», без Submit на площадке.
>
> Автозапуск включай отдельно по моей просьбе. В конце дай короткую инструкцию: адрес тренажёра, как открыть и остановить, где лежат мои данные и как сделать резервную копию. Честно укажи, что проверено, а что осталось сделать вручную.

## Шаги для помощника

1. Скачать ZIP или клонировать репозиторий. Выбрать путь вроде `~/Projects/algo-practice`; на Windows — папку пользователя без чужих данных. Не копировать готовую личную установку автора.
2. Проверить Python: `python3 --version` либо `py -3 --version`. Рекомендуется 3.11+.
3. Убедиться, что `data/catalog.json` существует, `static/vendor/monaco/vs/loader.js` на месте и нет чужого `data/state.json`. Если state уже есть, считать установку существующей и сохранять её.
4. Обычный запуск: `python3 launch.py` / `py -3 launch.py`. Если браузер не открылся — открыть http://127.0.0.1:8765 вручную.
5. При проблеме смотреть вывод или `data/server.log`. Не пытаться лечить локальный запуск установкой случайных пакетов. Внешние API-ключи не нужны.
6. Проверить `/api/bootstrap`:285 задач, solved0, drafts{}, jobs[], interview.status idle, remaining_seconds3600. Затем проверить интерфейс и Run/Debug на отдельном временном `--data-dir` или вернуть только свои тестовые черновики к исходному виду. Не удалять пользовательские записи.
7. Для macOS автозапуск — необязательные `python3 autostart.py install` и `status`, только после обычной проверки и из постоянной папки. Не запускать одновременно ручной сервер и службу на одном порту.

## Расширение — только если нужно

1. Запустить тренажёр. В браузере открыть `chrome://extensions`, включить режим разработчика, «Загрузить распакованное», выбрать `extension/`.
2. Скопировать **свой** ID расширения с этой страницы:32 буквы a–p.
3. В папке проекта выполнить:

   ```sh
   python3 bind_extension.py ID_РАСШИРЕНИЯ
   ```

   На Windows: `py -3 bind_extension.py ID_РАСШИРЕНИЯ`.

4. Открыть расширение, нажать «Подключить», обновить локальную вкладку. Файл `data/bridge-extension.json` остаётся личным и не отправляется в Git.
5. Войти в собственный аккаунт площадки. Сначала оставить «Только вставить код» включённым. После проверки выбранного Python и вставки кода пользователь может выключить эту опцию. Тогда последующее нажатие Submit в тренажёре отправляет одно настоящее решение.

Официальная отправка проверялась с Dia. Работа в других Chromium-браузерах зависит от их поддержки расширений; браузер не нужен для локального выполнения кода.
