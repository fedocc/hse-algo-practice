# Подключение Dia

1. Запустить локальный тренажёр и открыть `http://127.0.0.1:8765`.
2. В Dia открыть `chrome://extensions`, включить режим разработчика и выбрать «Загрузить распакованное расширение».
3. Выбрать эту папку `extension`, в которой находится `manifest.json`.
4. Скопировать свой ID расширения с этой страницы: 32 буквы a–p. В терминале в корне проекта выполнить `python3 bind_extension.py ТВОЙ_ID`, на Windows — `py -3 bind_extension.py ТВОЙ_ID`. Команда создаёт локальный `data/bridge-extension.json`. ID от чужой установки не подходит. Этот файл не отправляется в Git. При ошибке 403 сначала проверить привязку ID; сервер перечитывает файл без перезапуска.
5. Открыть расширение **Algo Practice — Dia Bridge** и нажать **Подключить**. Локальную вкладку тренажёра после первой установки обновить.
6. Готовый каталог уже содержит 285 задач, импорт для начала не требуется. Для обновления материалов войти в собственный Яндекс Контест в Dia и нажать **Все домашки двух курсов**. Расширение обработает каждый контест и каждую доступную задачу, сохраняя прогресс после каждого шага. Кнопка LeetCode обновляет встроенный список задач; недоступные условия не заменяются выдуманными. Старые Accepted площадки не прибавляются к новой цели, заработанный локальный прогресс сохраняется.

При первой проверке включён режим **Только вставить код**. Submit в тренажёре выбирает Python 3 и заполняет редактор задачи, но не нажимает «Отправить». После проверки вставки эту опцию можно выключить. Каждое последующее нажатие Submit в тренажёре разрешает одну официальную отправку соответствующего решения.

Сохраняются ID запроса и номера посылок до отправки. Старое успешное решение не считается новым результатом. Повторного нажатия Submit после сбоя нет: при неизвестном результате нужно проверить посылки на сайте и только затем отправлять снова.

Код работает в уже открытом сеансе браузера; расширение не читает cookies, пароли или файлы профиля. Условия и результаты передаются только локальному приложению. Разрешения ограничены localhost, страницами Контеста и LeetCode. `scripting` нужен для адаптера редакторов, `storage` — для восстановления импорта и защиты от повторной отправки, `alarms` — для возобновления фонового процесса.

В Manifest V3 фоновый процесс может останавливаться. Открытая вкладка тренажёра будит его каждые 2 секунды, запасной alarm — каждые 30 секунд. При закрытой вкладке импорт продолжается медленнее.

Редакторы поддерживаются через их собственные API: Monaco, Ace, CodeMirror или обычный textarea. Если язык или редактор сайта не распознан, расширение останавливается и оставляет сообщение; слепой отправки нет. Реальную совместимость со страницами установленной версии Dia необходимо проверить после загрузки.

Основные официальные источники: [Chrome scripting API](https://developer.chrome.com/docs/extensions/reference/api/scripting), [жизненный цикл MV3 worker](https://developer.chrome.com/docs/extensions/develop/concepts/service-workers/lifecycle).
