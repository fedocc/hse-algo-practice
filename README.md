# Algo Practice

Локальный тренажёр алгоритмов на Python: редактор Monaco, пошаговый Debug, результаты примеров в стиле LeetCode, карта тем и две задачи за час.

**Каждая новая установка начинает с 0/200.** В репозитории нет чужих решений, черновиков, заметок, истории отправок и настроек аккаунта.

## Быстрый запуск

Нужен **Python 3.11 или новее**. Для обычного запуска не нужны Node.js, npm, pip-пакеты или API-ключи: редактор уже включён.

1. Скачай репозиторий: **Code → Download ZIP**, распакуй в постоянную папку. Можно также использовать `git clone`.
2. Открой терминал в этой папке.
3. На macOS/Linux выполни:

   ```sh
   python3 launch.py
   ```

   На Windows, если Python установлен через официальный установщик:

   ```powershell
   py -3 launch.py
   ```

4. Откроется **http://127.0.0.1:8765** в обычном браузере. На Mac также можно открыть `Start Algo Practice.command`.

Альтернативный запуск с видимыми журналами: `python3 server.py` или `py -3 server.py`, затем открыть этот адрес вручную. Остановка — Ctrl+C. Проверка выполнялась на macOS; в код добавлены совместимые пути для Windows, но фактический запуск на Windows/Linux здесь не проверялся. На Windows при проблемах можно использовать WSL с Python 3.11+.

**Для установки с помощью своего GPT передай ему ссылку на репозиторий и [GPT_INSTALL.md](GPT_INSTALL.md).** В файле есть готовый запрос и список проверок. Если у помощника нет доступа к терминалу, выполняй предложенные команды самостоятельно.

## Что внутри

- **285 задач:** 211 из домашних работ, защит и переписываний двух курсов ФКН, 74 LeetCode.
- **275 загруженных условий.** У десяти LeetCode условие недоступно; такие задачи не выбираются автоматически в тренировку.
- **43 локальных набора по 100 тестов.** Среди них все 30 задач защит первого курса, префикс-/Z-функции и Ахо–Корасик. Остальные задачи можно проверять на примерах и в исходной системе.
- **Карта 30 тем** с зависимостями и прогрессом.
- **Интервью:** пара задач на 60 минут, пауза и подсчёт новых решений.
- **Теория:** краткие памятки, ссылки на источники и запрос для обсуждения темы с GPT. Отдельный платный API не подключён.

Начальная цель —200 задач к 16 марта 2027; её можно изменить в своей копии. Старые Accepted из аккаунта исходной системы не прибавляются к новому прогрессу.

## Run, Debug и Submit

**Run** выполняет все примеры в Testcase, включая добавленные через `+`. В Test Result можно переключать Case и смотреть Input, Output, Expected, время и Diff. Accepted здесь означает прохождение этих примеров. Run не отмечает всю задачу решённой.

**Debug** использует выбранный пример. Клик слева от номера строки ставит breakpoint; доступны шаг, вход в функцию, продолжение, стек и переменные. F10 — шаг, F11 — вход в функцию.

**Submit → Локально** проверяет подготовленный набор. Метка LOCAL относится только к нему. После 100/100 кнопка «Засчитать в прогресс» отмечает решение. Официальные и сгенерированные тесты различаются в сведениях о наборе.

**Submit → Dia** использует отдельное расширение и аккаунт владельца установки. Новая официальная отправка возвращает вердикт в историю. Accepted обновляет прогресс; ошибка не добавляет задачу и не снимает уже решённый статус. Старый вердикт не засчитывается повторно. В архивном Контесте может быть доступен только C++ или отправки могут быть закрыты — тогда используй локальный Python.

Локальные Run/Debug/Submit работают без расширения. Для официальной отправки см. [extension/README_INSTALL.md](extension/README_INSTALL.md).

## Данные и обновления

Пользовательские данные создаются локально в **`data/state.json`**. Для резервной копии сохрани этот файл. При обновлении кода оставь его на месте. Не скачивай чужой state.json и не заменяй свой файлом из чужой установки.

Чистый каталог — `data/catalog.json`; готовые проверки — `data/testpacks/`; изображения — `static/imported/statements/`. Всё необходимое для обычного запуска входит в репозиторий. Источники и ограничения наборов описаны в [THIRD_PARTY.md](THIRD_PARTY.md).

Сервер исполняет твой Python локально и слушает только 127.0.0.1. Не выставляй его в интернет и не запускай неизвестный код. На Windows остаются ограничения системных лимитов ресурсов; таймаут и ограничение вывода сохраняются.

## Необязательный автозапуск на macOS

После успешного обычного запуска останови вручную запущенный сервер. Затем из постоянной папки:

```sh
python3 autostart.py install
python3 autostart.py status
```

Служба запускается при входе в macOS и восстанавливается после остановки. Mac должен быть включён и не спать. Не меняй папку проекта после настройки автозапуска. На Windows/Linux автозапуск отдельно не устанавливается.
